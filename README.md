📌 Project Overview

Student performance can be influenced by factors such as study habits, attendance, and previous academic results.

This project uses a trained Machine Learning model to estimate exam scores from these academic inputs. A Flask web application makes the prediction process accessible through a simple browser interface.

✨ Key Features

- 🎯 Exam Score Prediction — estimates exam scores from academic inputs.
- 🧠 Machine Learning Model — uses Linear Regression.
- 🌐 Interactive Web Interface — enter values and view predictions.
- 📊 Model Evaluation — evaluates performance using R² score and Mean Absolute Error.
- 💡 Student Recommendations — provides personalized guidance based on inputs, where implemented.
- ☁️ Live Deployment — hosted using Render.
- 📂 Open Source — source code and project documentation are available on GitHub.

⚙️ How It Works

1. Input: Enter study hours, attendance, and previous scores.
2. Prepare: Format the input values for the trained model.
3. Predict: The Linear Regression model estimates the exam score.
4. Display: View the prediction on the web interface.

📊 Model Performance

The model was evaluated on a held-out test dataset.

Evaluation Metric| Result
R² Score| 0.5156
Mean Absolute Error (MAE)| 1.4631
Cross-validation Mean R²| 0.5912

Interpretation: The test R² score of approximately 0.516 indicates that the model explains around 51.6% of the variation in exam scores in the evaluated test set. The MAE of approximately 1.46 means predictions differed from actual scores by about 1.46 score units on average.

These results describe performance on the evaluated dataset and do not guarantee the same accuracy for every student or dataset.

💻 Run Locally

Follow these steps to run the project on your computer.

1. Clone the repository

git clone https://github.com/Gurusivasai-sunkari/Student-Performance-Predictor.git

2. Open the project folder

cd Student-Performance-Predictor

3. Create a virtual environment (recommended)

python -m venv venv

Activate it on Windows:

venv\Scripts\activate

4. Install dependencies

pip install -r requirements.txt

5. Run the application

python app.py

Open the local URL displayed in the terminal, commonly "http://127.0.0.1:5000".
